# המשחקים הבאים שלי

פורטל ספורט אישי (SPA, HTML יחיד, עברית/RTL, ערכת נושא כהה) עם מיקוד על דאלאס-פורט וורת', טקסס. PWA — ניתן להתקין כאפליקציה במסך הבית בטלפון.

## הפעלה מקומית

פתחו `index.html` ישירות בדפדפן, או הריצו שרת סטטי מקומי (נדרש כדי שה-service worker יירשם):

```
python3 -m http.server 8000
```

ואז גשו ל-http://localhost:8000

## פריסה (GitHub Pages)

הריפו הזה מוגדר לפריסה אוטומטית ל-GitHub Pages מהענף `main`. אחרי push, האתר יהיה זמין בכתובת:

```
https://<שם-המשתמש>.github.io/<שם-הריפו>/
```

## מבנה

- `index.html` — הפורטל עצמו.
- `manifest.json`, `sw.js`, `icon-*.png`, `apple-touch-icon.png` — קבצי PWA.
- `CLAUDE.md` — יומן שינויים והנחיות פיתוח לפרויקט.
